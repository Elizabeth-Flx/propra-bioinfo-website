# Step 2 #
Das Ergebnis der Suche ergibt, dass das Gen aus dem Coronavirus genome (Severe acute respiratory syndrome coronavirus 2 isolate SARS-CoV-2/human/USA/NY-PV09466/2020). Das kann den Ergebnissen der BLAST-Suche entnommen werden.

# Step 4 #
Der E-Value ist ein Parameter, der die Nummer der Treffer, die man zufällig bei einer bei einer BLAST-Suche erwarten kann, angibt. Er sinkt exponentiell wenn der Score des Matches sich erhöht. (https://blast.ncbi.nlm.nih.gov/Blast.cgi?CMD=Web&PAGE_TYPE=BlastDocs&DOC_TYPE=FAQ#expect)
