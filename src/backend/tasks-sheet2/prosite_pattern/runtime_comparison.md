# Runtime
Based on my testing, I didn't notice a significant difference in runtime between my local implementation and the database method. 

Though there are a few factors to consider that may affect the runtime of the database method. For example, poor internet connection could result in slow or unreliable connectivity, which would decrease runtime compared to local execution. 

If the database is handling a large amount of sequence data, it may be faster than my local implementation, as most database servers have good parallelization functionality that can increase performance. Though on smaller requests a speedy computer could still outperform the database request.
